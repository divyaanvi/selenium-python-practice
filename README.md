# Selenium Python Automation - SauceDemo

## Project Description
This project contains automated UI test scripts for the SauceDemo web application using Selenium WebDriver and Python.

## Test Coverage
- Login Validation
- Product Verification
- Product Price Verification
- Product Count Validation
- Add to Cart Functionality
- Checkout Functionality
- Product Sorting

## Tools Used
- Python
- Selenium WebDriver
- Pytest
- GitHub
